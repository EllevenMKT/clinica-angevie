# Site — Clínica Angevie

## Estrutura
- `index.html` — a página inteira (conteúdo, meta tags de SEO, dados estruturados)
- `css/style.css` — todo o visual (cores, fontes, layout, carrossel)
- `assets/` — logos e foto da Dra. Aline
- `assets/results/` — fotos de antes/depois do carrossel de Resultados
- `robots.txt` — libera indexação pros buscadores
- `sitemap.xml` — mapa do site pro Google

## Seções do site
1. Hero (destaque inicial)
2. Diferenciais
3. Procedimentos
4. **Resultados** — carrossel de antes/depois (novo)
5. Sobre (Dra. Aline)
6. Contato (CTA final)

## SEO já implementado
